# Game615 - 小游戏集合

这是一个基于 Godot 引擎开发的小游戏集合项目，目前包含坦克游戏等有趣的游戏内容。

## 技术栈

- **游戏引擎**: Godot 4.4
- **编程语言**: GDScript
- **渲染器**: Forward Plus

## 游戏内容

### 坦克游戏 (Tanker Game)
- 多种颜色的坦克可供选择（蓝色、青色、绿色、橙色、紫色、红色、黄色）
- 流畅的坦克动画效果
- 支持自定义游戏逻辑扩展

## 如何运行

1. 确保您已安装 [Godot 4.4](https://godotengine.org/download/) 或更高版本
2. 克隆或下载本项目
3. 打开 Godot 引擎，点击 "导入" 按钮
4. 选择项目根目录下的 `project.godot` 文件
5. 点击 "导入并编辑" 按钮
6. 在编辑器中点击播放按钮或按 F5 运行游戏

## 项目结构

```
game615/
├── .godot/              # Godot 引擎配置文件
├── asset/              # 游戏资源
│   └── tanker/         # 坦克资源文件
├── tanker_game/        # 坦克游戏目录
│   └── tanker.tscn     # 坦克游戏场景
├── icon.svg            # 项目图标
├── project.godot       # 项目配置文件
└── README.md           # 项目说明文档
```

## 游戏特性

- 高分辨率窗口 (1920x1080)
- 可扩展的游戏架构
- 丰富的视觉效果
- 支持跨平台运行

## 开发说明

### 添加新游戏

1. 在项目根目录下创建新的游戏文件夹（如 `new_game/`）
2. 创建游戏场景文件（如 `new_game.tscn`）
3. 在 `project.godot` 中配置游戏入口
4. 添加所需的资源文件到 `asset/` 目录

### 自定义坦克

1. 在 `asset/tanker/` 目录下添加新的坦克图片
2. 在 `tanker_game/tanker.tscn` 中编辑 `SpriteFrames` 资源
3. 添加新的坦克动画并设置相应的纹理
